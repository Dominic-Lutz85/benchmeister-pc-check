# Dateien, Ordner, Pfade

**Lernfeld 01, Kapitel 2** · 20 Minuten · [[LF01 Wie das Web funktioniert|Lernfeld oeffnen]]

- [ ] Kapitel gelesen und Aufgabe gemacht

> [!abstract] Ziel
> Du legst ein Projekt so an, dass Verweise auch nach dem Hochladen noch stimmen.

## Das musst du wissen

- `index.html` ist der Standardname der Startseite. Wer einen Ordner aufruft, bekommt diese Datei, ohne sie zu nennen.
- **Relative Pfade** gehen vom aktuellen Dokument aus: `bilder/foto.jpg` liegt daneben, `../stil.css` eine Ebene hoeher. **Absolute Pfade** beginnen mit `/` und gehen immer von der Wurzel der Seite aus.
- Kleinschreibung, keine Leerzeichen, keine Umlaute in Dateinamen. Auf Windows faellt das nicht auf, auf dem Server dann sofort. Das ist der haeufigste Grund, warum lokal alles geht und online nichts.
- Eine brauchbare Grundstruktur: `index.html`, `css/`, `js/`, `bilder/`. Mehr braucht ein kleines Projekt nicht.
