# Werkzeugkasten einrichten

**Lernfeld 01, Kapitel 5** · 25 Minuten · [[LF01 Wie das Web funktioniert|Lernfeld oeffnen]]

- [ ] Kapitel gelesen und Aufgabe gemacht

> [!abstract] Ziel
> Dein Rechner ist arbeitsbereit, und du weisst, wofuer jedes Werkzeug da ist.

## Das musst du wissen

- **Editor:** VS Code ist der Standard. Wichtige Erweiterungen zum Start: Live Server (Seite laedt bei jedem Speichern neu), Prettier (formatiert automatisch), und sonst erstmal nichts.
- **Browser:** mindestens zwei, davon einer aus einer anderen Familie (Firefox neben Chrome). Was in beiden geht, geht meistens ueberall.
- **Git:** deine Sicherung und deine Zeitmaschine. Kommt ausfuehrlich in Lernfeld 11, aber installiere es jetzt, damit es da ist.
- Widerstehe dem Werkzeugrausch. Jedes Werkzeug, das du nicht erklaeren kannst, ist eine Fehlerquelle, die du spaeter nicht findest.

## Aufgabe

> [!todo] Selber machen
> Installiere VS Code mit Live Server, oeffne dein Uebungsprojekt darin und aendere eine Ueberschrift. Der Browser soll ohne dein Zutun aktualisieren.
