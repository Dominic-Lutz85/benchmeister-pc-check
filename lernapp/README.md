# Werkbank Webdesign

Eine Lern-App fuer den Weg zum Webdesigner. Eine einzelne HTML-Datei,
ohne Abhaengigkeiten, ohne Bauprozess.

## Inhalt

12 Lernfelder mit 65 Kapiteln, von "wie kommt eine Seite in den Browser"
bis "Angebot schreiben und rechtssicher ausliefern". Jedes Kapitel hat:

- ein Lernziel in einem Satz
- den Kern in vier Punkten
- eine Praxisaufgabe
- eine Selbstpruefungsfrage
- eine Videosuche und ein bis zwei Quellen

Dazu sechs Praxisprojekte, die nacheinander freigeschaltet werden.

## Warum Suchlinks statt fester Videos

Einzelne YouTube-Videos werden geloescht oder auf privat gestellt. Ein
toter Link ist schlimmer als eine Suche, deshalb steht in jedem Kapitel
ein vorbereiteter Suchbegriff plus die Empfehlung, welchem Kanal man
trauen kann.

## Fortschritt

Wird im Browser gespeichert (localStorage). Als veroeffentlichtes
Artefakt zusaetzlich in der Artefakt-Datenbank, damit der Stand auf
mehreren Geraeten gleich ist. Ohne beides funktioniert die App
weiterhin, nur ohne Gedaechtnis.

## Oeffnen

Datei im Browser oeffnen. Fuer die Schriften ist eine Internetverbindung
noetig, ohne sie greift die Rueckfallkette.
